Exploratory Data Analysis (EDA) – Layoffs Dataset

📌 Project Overview

This project performs Exploratory Data Analysis (EDA) on a global layoffs dataset using MySQL Workbench.

The objective is to explore company layoffs, identify trends, and discover insights across different industries, companies, countries, and time periods.

🛠️ Tools Used

- MySQL
- MySQL Workbench
- SQL

🎯 Key Analysis

- Total layoffs and percentage of workforce laid off
- Companies with the highest number of layoffs
- Layoffs by industry and country
- Layoffs by year and month
- Company stage analysis
- Rolling total of layoffs over time

📊 Key SQL Concepts

- SELECT, WHERE, ORDER BY
- GROUP BY and aggregate functions
- Common Table Expressions (CTEs)
- Window Functions
- Date Functions
- Subqueries

📁 Project Files

- "EDA.sql" – SQL queries used for the analysis
- "layoffs_staging2.csv" – Dataset used for the project
