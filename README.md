MySQL Data Cleaning Project

Project Overview

This project focuses on cleaning and preparing a real-world layoffs dataset using MySQL.

The main objective is to improve data quality, consistency, and reliability before performing further data analysis.

Tools Used

- MySQL
- MySQL Workbench
- SQL

Dataset

Layoffs dataset containing company layoff information.

Data Cleaning Steps

1. Created a staging table to protect the raw dataset.
2. Identified and removed duplicate records.
3. Standardized inconsistent data.
4. Handled NULL and blank values.
5. Removed unnecessary columns and rows.
6. Prepared the final cleaned dataset.

SQL Skills Demonstrated

- CREATE TABLE
- INSERT INTO
- ROW_NUMBER()
- Common Table Expressions (CTEs)
- UPDATE
- DELETE
- ALTER TABLE
- TRIM()
- CASE statements
- JOIN
